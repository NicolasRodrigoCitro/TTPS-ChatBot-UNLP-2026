El frontend del chatbot academico, el cual se comunica con el backend para usar IA para responder las consultas academicas.

El frontend usa Ionic 7 y Angular +14 para poder ser integrado con la app Informatica UNLP de Android.

### ▶ Cómo correr

Para usar se necesita instalar ionic con `npm i -g @ionic/cli@7.0`.

Para correr se usa `ionic s`, la primera vez se instalaran las dependencias necesarias.
